# Faith on Joy Mountain

A responsive, static ministry website designed to replace the current Wix site. It contains no database or paid-server requirement and is structured for eventual GitHub Pages hosting.

## Updating articles

Add a new entry to the `articles` list in `app/content.ts`. The Articles grid is generated automatically from that list.

## Local preview

Install dependencies and run the development script. No publishing or domain configuration is included in this initial version.
